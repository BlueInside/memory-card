# Memory Game

## Overview

This is a simple memory game built with React. The objective of the game is to click on characters that have not been clicked before. The game features 12 unique characters. If you click on a character that you have already clicked, the game resets.

## Features

- **12 Unique Characters**: The game consists of 12 different characters.
- **React**: Built using React for a seamless and interactive user experience.
- **State Management**: Utilizes React's state management to keep track of clicked characters.
- **Responsive Design**: The game is designed to be responsive and works well on different screen sizes.

## How to Play

1. **Start the Game**: The game starts automatically when you load the page.
2. **Click a Character**: Click on any character that you have not clicked before.
3. **Avoid Repeats**: If you click on a character that you have already clicked, the game will reset.
4. **Score Points**: Every time you click a new character, you score a point.
5. **Reset on Repeat**: If you click a character you already clicked, the game resets, and you can start again to beat your previous score.



### Prerequisites

- Node.js and npm installed on your machine.

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/yourusername/memory-game.git
   ```
2. Navigate to the project directory:
   ```bash
   cd memory-card
   ```
3. Install the dependencies:
   ```bash
   npm install
   ```
### Running the game

1. Start the development server:
   ```bash
   npm start
   ```
2. Open your browser and go to http://localhost:5173 (may differ, see the console) to play the game.
